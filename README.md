# Ticketmaster Queue Monitor

Automated tool for monitoring Ticketmaster queues and generating queue links with CAPTCHA solving capabilities.

## Features
- Browser Automation for queue monitoring
- Generate Queue Links with continuous processing
- Automatic CAPTCHA solving using OCR
- Proxy support for multiple IP addresses
- Real-time status updates

## Setup
1. Install dependencies: `npm install`
2. Run the application: `npm start`

## Files
- `main.js` - Main Electron process
- `renderer.js` - Frontend logic
- `index.html` - User interface
- `style.css` - Styling
- `package.json` - Dependencies and scripts
